# CENTCOM NC

Scanner, events, campus, business, and news for St. Lawrence County, New York.
Published at https://julietdeltaone.github.io/CENTCOM-NC/

## Files

- `index.html` — the stream page; loads `data/items.json` when it opens
- `sources.html` — source health page; loads `data/sources.json` when it opens
- `data/items.json` — the current items, written by the feed routines
- `data/sources.json` — the source health checks, written by the audit routine
- `.nojekyll`

Status: draft with sample items; live feeds are not wired in yet.
